# Face Recognition ด้วย KNN

จำหน้าคนจากกล้องเว็บแคมด้วย K-Nearest Neighbors ที่เขียนเอง ใช้พิกเซลของภาพเป็นข้อมูลโดยตรง ไม่ใช้ scikit-learn

## ไฟล์ในโปรเจกต์

- `Get_data.py` เก็บภาพหน้าจากกล้องลง `DATA/<ชื่อ>/`
- `face_reg.py` จำหน้าแบบสด และมีโหมดวัดความแม่น
- `DATA/` มี 6 คน คนละ 4 ภาพ ภาพเป็นขาวดำขนาด 140×180

## ติดตั้ง

```bash
python -m venv .venv
.venv\Scripts\activate        # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

ต้องใช้ OpenCV 4.x เท่านั้น เพราะ OpenCV 5 ตัด `CascadeClassifier` (Haar cascade) ที่ใช้หาใบหน้าออกไปแล้ว

## วิธีใช้

```bash
python Get_data.py Somchai     # กด s เพื่อบันทึก กด q เพื่อออก (ควรเก็บอย่างน้อยคนละ 4 ภาพ และหันหน้าหลายมุม)
python face_reg.py eval        # วัดความแม่นจากภาพใน DATA/ ไม่ต้องเปิดกล้อง
python face_reg.py             # เปิดกล้องแล้วแสดงชื่อพร้อมระยะห่าง กด q เพื่อออก
```

## ขั้นตอนการทำงาน

1. **หาใบหน้า**: ใช้ Haar cascade หาหน้าในภาพจากกล้อง แล้วขยายกรอบให้มีสัดส่วน 140:180 เท่ากับภาพใน `DATA/` ถ้าหาไม่เจอ `Get_data.py` จะใช้กรอบคงที่แบบเดิมแทน
2. **แปลงเป็นเวกเตอร์**: ย่อภาพเหลือ 35×45 แล้วหารด้วย 255 ได้เวกเตอร์ยาว 1,575 ค่า
3. **KNN**: คำนวณระยะ Euclidean ไปยังภาพทุกภาพใน `DATA/` แล้วตอบชื่อของภาพที่ใกล้ที่สุด

## ผลการวัด (leave-one-out)

ซ่อนภาพทีละภาพแล้วให้โมเดลทายจากภาพที่เหลืออีก 23 ภาพ

| ตั้งค่า | k = 1 | k = 3 |
|---|---:|---:|
| พิกเซลเต็ม 140×180 (โค้ดเดิม) | 14/24 | 12/24 |
| **ย่อเหลือ 35×45 (ค่าปัจจุบัน)** | **14/24 (58%)** | 12/24 |
| ย่อ 35×45 + `equalizeHist` | 12/24 | 9/24 |

ถ้าสุ่มทายจะได้ประมาณ 1/6 หรือ 17%

- **k = 1 ดีกว่า k = 3** เพราะแต่ละคนมีแค่ 4 ภาพ พอซ่อนไป 1 ภาพก็เหลือ 3 ภาพ การโหวต 3 เสียงจึงโดนคนอื่นแย่งได้ง่าย
- **ย่อภาพแล้วแม่นเท่าเดิม** แต่คำนวณน้อยลง 16 เท่า
- **`equalizeHist` ทำให้แย่ลง** เพราะภาพในชุดนี้ถ่ายในห้องเดียวกัน แสงคล้ายกันอยู่แล้ว การปรับแสงเลยไปขยายความต่างของพื้นหลังแทน

## ข้อจำกัด

- พิกเซลดิบจะเปลี่ยนมากเมื่อหันหน้าหรือเงยหน้า ภาพที่หันไม่เหมือนภาพอื่นของคนเดียวกันจึงทายผิดบ่อย วิธีแก้ที่ได้ผลที่สุดคือเก็บภาพเพิ่ม คนละ 10–20 ภาพหลายมุม
- ระยะห่างของภาพคนเดียวกัน (5.2–9.0) กับภาพของคนอื่น (6.7–10.0) ยังซ้อนทับกันอยู่ ถ้าตั้งเกณฑ์ "Unknown" ตอนนี้ก็จะตัดถูกบ้างผิดบ้าง
- Haar cascade ใช้ได้ดีเมื่อมองหน้าตรง ถ้าหันข้างมากจะหาใบหน้าไม่เจอ
